# PRD - Todo 앱 (초안)

> 출처: docs/IDEA.md
> 상태: 초안 (검토 전)

## 1. 목표
- 혼자 쓰는 간단한 할 일 목록 웹 앱을 만든다.
- 할 일을 추가하고, 완료 처리하고, 삭제할 수 있다.
- 새로고침해도 데이터가 유지된다.
- 초보자가 단계별(v0.1 → v1.0)로 따라가며 배울 수 있는 작은 프로젝트로 유지한다.

## 2. 대상 사용자
- 본인 혼자 사용하는 개인 사용자 (1인 사용)
- 계정, 협업, 공유가 필요 없는 사람
- 복잡한 기능 없이 빠르게 할 일을 적고 지우고 싶은 사람

## 3. 기능 목록

### MVP
| ID | 기능 | 설명 | 규칙 |
|----|------|------|------|
| F-01 | 할 일 추가 | 제목을 입력해 새 할 일을 만든다 | 제목 필수, 앞뒤 공백을 지운 뒤 1~100자 (공백만 입력하면 추가되지 않음) |
| F-02 | 할 일 목록 보기 | 저장된 할 일을 목록으로 보여준다 | 최신순 정렬 |
| F-03 | 완료/미완료 전환 | 체크박스로 완료 상태를 바꾼다 | 다시 누르면 미완료로 돌아감 |
| F-04 | 할 일 삭제 | 선택한 할 일을 목록에서 제거한다 | - |
| F-05 | 데이터 유지 | 새로고침해도 할 일이 사라지지 않는다 | 저장 방식은 버전별로 다름 (아래 참고) |

### 버전별 구현 범위
| 버전 | 내용 | 관련 기능 |
|------|------|-----------|
| v0.1 | 화면만 (브라우저 메모리) | F-01 ~ F-04 (※ 새로고침 시 데이터는 사라짐) |
| v0.2 | API 연결 (서버 메모리) | F-01 ~ F-04 |
| v0.3 | DB 저장 | F-05 완성 |
| v0.4 | 필터와 수정 | (기능 정의는 이 버전을 시작할 때 추가) |
| v1.0 | 배포 | 전체 |

## 4. 사용자 스토리
- **F-01** 사용자로서, 해야 할 일을 제목으로 빠르게 추가하고 싶다. 그래야 잊지 않고 기록할 수 있다.
- **F-02** 사용자로서, 내가 적은 할 일을 최신순으로 한눈에 보고 싶다. 그래야 방금 추가한 일을 바로 확인할 수 있다.
- **F-03** 사용자로서, 끝낸 일을 체크박스로 표시하고 싶다. 그래야 무엇이 남았는지 구분할 수 있다.
- **F-03** 사용자로서, 잘못 체크한 일을 다시 미완료로 돌리고 싶다. 그래야 실수를 바로잡을 수 있다.
- **F-04** 사용자로서, 필요 없어진 할 일을 삭제하고 싶다. 그래야 목록이 깔끔하게 유지된다.
- **F-05** 사용자로서, 페이지를 새로고침해도 할 일이 그대로 남아 있길 원한다. 그래야 앱을 믿고 쓸 수 있다.

## 6. 성공 기준
- [ ] 제목 1~100자로 할 일을 추가할 수 있고, 빈 제목(공백만 입력 포함)이나 100자 초과는 추가되지 않는다 (F-01)
- [ ] 목록이 최신 추가 순으로 보인다 (F-02)
- [ ] 체크박스로 완료/미완료를 오갈 수 있다 (F-03)
- [ ] 삭제한 할 일은 목록에서 사라진다 (F-04)
- [ ] v0.3 이후, 새로고침과 서버 재시작 후에도 데이터가 남아 있다 (F-05)
- [ ] 위 동작이 자동 테스트로 확인된다 (화면: Jest + React Testing Library, API: pytest)
- [ ] v1.0에서 배포된 주소로 접속해 위 기능을 모두 사용할 수 있다
